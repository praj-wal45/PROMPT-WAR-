Job seekers and renters lose millions of dollars to fake appointment letters, pay-for-equipment phishing, check-cashing schemes, and deposit traps that routinely bypass standard email spam filters. 

The **Fake Offer Letter & Phishing Inspector** is a high-performance single-page security web application designed to parse appointment copy, evaluate domain authenticity, uncover financial traps, and compute a dynamic **Scam Threat Index (0–100%)**.

## 🚀 Key Features

1. **Multi-Input Parsing Widget**:
   - **Direct Text Area**: Large text editor with live character counter for email headers, contracts, and letters.
   - **File Upload**: Client-side document parser supporting PDF, TXT, and scanned documents.
   - **URL Scanner**: Evaluates suspicious job portal links and recruiter domains.
   - **Preloaded Demos**: Instant test buttons for *Pay-For-Equipment Scam*, *Legitimate Stripe Offer*, and *Rental Wire Trap*.

2. **Animated SVG Radial Threat Gauge (0–100%)**:
   - **0% – 30%**: `LOW RISK / VERIFIED SAFE` (Neon Emerald)
   - **31% – 65%**: `CAUTION / SUSPICIOUS ANOMALIES` (Amber Warning)
   - **66% – 100%**: `CRITICAL THREAT / PHISHING SCAM` (Crimson Danger)

3. **Sub-Score Breakdown**:
   - **Domain & Metadata Credibility** (Free webmail handles, spoofing, recruiter channel validation).
   - **Financial & Deposit Trap Risk** (Mailed checks, vendor hardware payments, Zelle/crypto).
   - **Communication & Urgency Pressure** (Sub-24h deadlines, Telegram/WhatsApp interviews, mass salutations).

4. **Sentence-Level Threat Highlighter**:
   - Renders analyzed text with interactive red (Critical) and yellow (Warning) highlighted spans.
   - Click or hover any highlighted sentence to open the Vector Inspector explaining the scam mechanics.

5. **Actionable Remediation & PDF Export**:
   - Step-by-Step guidance to prevent financial loss and identity theft.
   - Direct reporting links to **FBI IC3 (ic3.gov)**, **FTC (reportfraud.ftc.gov)**, and **ICANN WHOIS**.
   - Printable **Formal Cybersecurity Audit Certificate**.

6. **Optional AI Model Integration**:
   - Built-in heuristic engine runs 100% offline.
   - Optional Gemini API key support for secondary neural validation.
